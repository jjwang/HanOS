Detailed Description

Definitions for signal handling. 

 This file contains the definitions and structures used for signal handling
 within the HanOS kernel. It includes definitions for signal sets, signal
 actions, and various signal-related constants. The functions provided allow
 for setting signal actions, changing signal masks, and managing signals
 within processes.

uint64_t rax

Register frame saved by the syscall entry stub.

Signal frame pushed on the user stack before a handler runs.

The stub pushes the 15 general-purpose registers (rax first), then the interrupted RIP/CS/RFLAGS and RSP/SS. Unlike exception_regs_t it has no error-code slot.

pretcode is the return address the handler's ret pops, so it sits at the frame's base. rt_sigreturn recovers the frame from rsp - 8.
