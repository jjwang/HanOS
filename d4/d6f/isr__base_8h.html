Definition isr_base.s:68

Register frame saved by the exception/IRQ entry stubs.

The stubs push the 15 general-purpose registers (rax first, r15 last), then the error code the CPU pushed for the fault (a zero is pushed when the exception has none), then the interrupted RIP/CS/RFLAGS and, on a privilege change, RSP/SS. This is not process_regs_t, which models the context-switch frame and has no error-code slot.
