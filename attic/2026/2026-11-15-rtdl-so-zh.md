# 2026-11-15：加入运行时链接器与共享对象

通过共享 musl loader 加载 `PT_INTERP` 程序。

## 内核

- `elf_load` 把 `ET_DYN` 解释器映射到固定运行时链接器基址。辅助向量加入 `AT_BASE`。
- 辅助向量改用 Linux 键值：`AT_PHDR`、`AT_PHENT`、`AT_PHNUM`、`AT_BASE`、`AT_ENTRY`。
- 没有 `PT_PHDR` 的静态程序写出 `AT_PHNUM=0`。解释器不会读取空程序头表。
- `mmap` 接受文件映射。每进程缓存读入一次文件，再按页切片。
- 新增传统 `open` 系统调用与 `mprotect`。loader 重定位共享对象时调用两者。

## 镜像

- `/lib/ld-musl-x86_64.so.1` 与 `/lib/libc.so` 来自 musl 共享构建。
- 静态 server 与应用仍为默认。动态程序用 `PT_INTERP=/lib/ld-musl-x86_64.so.1`。
- `make initrd` 把两个文件打包进 `lib`。

## BFD 断言

- binutils 2.35 在链接 `-mcmodel=large` PIC 共享对象时断言于 `bfd/elflink.c:14788` 的 `elf_append_rela`。重定位数量超过 `.rela.dyn` 分配大小。
- 去掉 `--gc-sections`、`--exclude-libs`、`--dynamic-list`、`--hash-style`、`--no-undefined` 后仍会断言。
- loader 改用 `-mcmodel=small` 构建。用户程序继续用 `-mcmodel=large`。
- `3rdparty/musl/build-shared.sh` 用 `x86_64-elf-gcc` 编译，用 `x86_64-elf-ld` 链接。不调用本机 gcc。

## 测试

- 动态 hello 通过共享 loader 运行。
- 动态程序通过 `mmap` 加载 `libgreet.so`，输出 `shared greet`。
- 静态启动与 CI 仍通过。
