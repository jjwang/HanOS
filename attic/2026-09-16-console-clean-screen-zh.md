# 2026-09-16：终端服务从干净屏幕开始

## 概述

修复启动闪屏（HNK 点阵大字）以及内核终端残留内容出现在用户态终端上的问题。
此前终端服务会继承内核的帧缓冲；如果内核在服务已复制之后又把自己终端的后备
缓冲区刷到屏幕，被清掉的 logo（或旧内容）就会重新出现。

## 变更

- `userspace/console.c`：启动时清空后备缓冲区并整体刷一次，而不再复制内核
  帧缓冲。屏幕归服务所有，不应继承启动日志或闪屏。
- `kernel/kmain.c`：仅在终端服务未激活时调用 `term_refresh()`，避免内核把
  自己终端的后备缓冲区刷到服务端画面上。

## 测试

- `make -C kernel clean && make -C kernel` 与用户态构建均无警告；完整镜像可
  构建。
- QEMU：启动并执行若干命令后，屏幕只显示横幅、提示符与命令输出，下半部分
  为黑色；shell 仍可运行 `ls`/`pwd`，启动到达 `name "hansh"`，无 panic。
