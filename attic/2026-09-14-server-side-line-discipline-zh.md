# 2026-09-14：服务端行规程

## 概述

把终端行规程（可见行长度、退格处理、回车与文件结束）移入用户态输入服务。当输入服务
接管键盘时，内核 tty 对它收到的字节流只做透传；内核内驱动仍沿用 tty 自身的过滤。

## 改动

- `userspace/input.c` 记录当前行可见字符数，并：
  - 仅在该行非空时发出退格；
  - 在回车时重置该行；
  - 在 Ctrl-D 时重置该行并发送文件结束；
  - 通过控制台 endpoint 回显每个发出的字符。
- `libc/bootinfo.h`：`INPUT_KEY_EOF` 改为 `0xFF`，使其在截断到 8 位后与内核的
  `EOF` 字节一致。
- `kernel/fs/ttyfs.c`：输入服务活动时，tty 原样存入收到的字节（服务已应用行规程）。
  原有的“可见长度”退格过滤仅在内核内键盘路径下保留。

## 变更文件

| 文件 | 变更 |
|------|------|
| `userspace/input.c` | 行长度跟踪、退格/回车/EOF 行规程 |
| `libc/bootinfo.h` | `INPUT_KEY_EOF` 与内核对齐 |
| `kernel/fs/ttyfs.c` | 输入服务活动时透传 |

## 测试

- 服务开启：输入 `l`、`x`、退格、`s`、回车执行 `/bin/ls`（退格擦除 `x`），随后
  `pwd` 正常。
- 服务关闭：内核内键盘下同样的按键序列仍执行 `/bin/ls`。
- 全量构建无告警。
