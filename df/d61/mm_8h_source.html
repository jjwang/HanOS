96/* According to Intel's manual, only when CACHE_DISABLE and WRITETHROUGH
97 * are both set to 1, the MMIO will be strong uncacheable (UC) which can
98 * meet requirements of some memory regions, e.g., xAPIC memory address.

100 * when running on NEC VersaPro which has a i5-6200U CPU.
